# 페이지별 기능 분해

공통 화면: ERP 로고 오른쪽 아이콘으로 메뉴 접기, 접힌 상태에서 본문 왼쪽 위의 `>` 버튼으로 펼치기. 브라우저에 선택 상태 저장 및 같은 브라우저 창 간 동기화. 메뉴를 접으면 본문 영역을 확장하고 숨겨진 메뉴는 키보드 탐색에서 제외합니다.

메뉴 항목 왼쪽 점 손잡이로 순서를 변경합니다. Public/Private 그룹 경계를 넘는 이동은 취소하고 대시보드는 고정합니다. 드래그 삽입 선·가장자리 자동 스크롤·Escape 취소·손잡이 방향키 이동을 지원하며, 작은 화면의 가로 메뉴에서도 같은 그룹 안에서 이동합니다. 순서는 계정별 localStorage에 저장하고 같은 계정의 창끼리 동기화합니다. 저장된 값은 현재 그룹 구성으로 검증해 잘못된 항목·중복·다른 그룹 항목을 제외하고 신규 메뉴는 뒤에 추가합니다.

## 1. 오늘 상태 대시보드

메뉴는 PRIVATE(작업 타임라인·할 일)와 PUBLIC(그 외 업무 메뉴)으로 구분합니다. 대시보드의 TODO·진행 작업·자동 이월은 로그인 계정 전용이고, 일정·회의·부재·프로젝트는 공용입니다. API에서도 계정 소유권을 검사하며 관리자에게 다른 계정의 개인 기록 조회 권한을 부여하지 않습니다. 계정 도입 전 작업·할 일·주간 보고서는 admin에 귀속합니다.

공통 인증: `/login`에서 로그인하며 관리자 계정은 `/admin`, 일반 계정은 대시보드로 이동합니다. `/admin`에서 ID·비밀번호·이름·직함을 등록하고 계정 목록을 조회합니다. 페이지·데이터 API·첨부 파일에 세션 인증을 적용하며 관리자 기능은 관리자만 사용합니다. 영수증·재택근무·뽀모도로·채팅 이름은 로그인 계정에서 자동 적용합니다. 작업·프로젝트 담당자와 일정·회의록 참석자는 로그인 이름을 기본값으로 넣고 수정 가능합니다. 상단에서 이름·직함 확인과 로그아웃을 지원합니다.

- 오늘 날짜 기준 TODO 완료율 표시
- 오늘 일정 수 표시
- 현재 진행 중인 작업바 수 표시
- 진행 중인 프로젝트 수 표시
- 미완료 TODO를 오늘 날짜로 자동 이월한 뒤 목록 표시

담당 API: `app/routers/dashboard.py`

## 2. 달력

- 월 단위 달력 표시
- 달력 첫 칸부터 마지막 칸까지 일정을 조회해 함께 보이는 이전·다음 달 날짜에도 단일·기간 일정을 표시 (`/api/calendar?start_date=YYYY-MM-DD&end_date=YYYY-MM-DD`)
- 날짜 클릭 시 선택 날짜 변경
- 연차, 반차, 미팅, 회사 일정, 기타 일정 등록
- 참석자와 메모를 Obsidian 노트 본문으로 저장
- 연차·반차·재택 탭에서 등록한 일정을 동일한 캘린더 노트로 조회, 오전·오후 반차와 재택 유형 표시
- `/calendar?date=YYYY-MM-DD&event=ID` 주소로 해당 날짜와 일정 상세 열기

담당 API: `app/routers/calendar.py`

## 3. 작업 타임라인

- 계정별 개인 작업만 조회·등록·수정·삭제하며 다른 계정의 작업을 부모로 지정할 수 없음

- JIRA 이슈처럼 작업명, 담당자, 상태, 우선순위 등록
- start date와 end date를 기반으로 가로 작업바 표시
- 프로젝트와 작업을 연결할 수 있는 project_id 필드 제공

담당 API: `app/routers/tasks.py`

## 4. TODO 및 주간 보고서

- 계정별 개인 TODO, 순서·이월·완료 연결·보고서 분리
- 노트 상담봇에서도 본인 개인 기록과 공용 자료만 검색. 파일 접근 가능한 AI 실행은 중단하고 로컬 검색·보고서 집계를 사용

- 날짜별 TODO 등록
- 체크하지 못한 과거 TODO를 오늘 날짜로 자동 이월
- 이월된 TODO는 source_id로 원본과 연결
- 주간 TODO와 작업 타임라인을 모아 Markdown 보고서 생성
- 보고서는 `vault/Reports`에 저장되어 Obsidian에서 문서로 열람 가능

담당 API: `app/routers/todos.py`

## 5. 프로젝트 기록

- 상단 `+` 버튼으로 회사명과 프로젝트명 입력 후 프로젝트 생성
- 프로젝트 카드를 클릭하면 상세 팝업 표시
- 상세 팝업 상단에서 회의록/Wiki 탭 전환
- 상세 팝업 왼쪽 1/3 영역에서 등록된 글 목록 표시
- 상세 팝업 오른쪽 영역에서 선택 글 보기, 새 글 작성, 수정, 삭제
- 회의록과 Wiki에 이미지를 첨부하고 팝업에서 바로 표시
- 프로젝트 노트는 LLM이 프로젝트 맥락을 읽을 수 있도록 goals와 links를 frontmatter에도 보관

담당 API: `app/routers/projects.py`

## 6. 회의록

- 회의명, 일자, 시간, 참석자, 안건, 회의 내용, 이미지 저장
- 회사명을 먼저 등록하고 회의록에서 선택, 같은 이름 중복 등록 방지
- 일반 회의록과 프로젝트 회의록에서 공통 회사 목록 사용, 목록·상세에 회사명 표시
- 회사별 보기 필터와 주소 복원, 기존 회사 미지정 회의록에 회사 연결
- 회의록은 `vault/Meetings` Markdown 노트로 저장
- 목록에서 문서 선택 또는 수정 버튼으로 기존 내용 편집, 저장·취소 지원
- 안건, 본문 속 제목·목록, 기존 이미지, 프로젝트 연결 및 변경 이력을 보존하며 수정

담당 API: `app/routers/meetings.py`

## 7. Wiki

- 운영 절차, 프로젝트 지식, 의사결정 맥락을 자유 문서로 저장
- 카테고리와 태그를 frontmatter에 보관하고 본문은 Markdown으로 저장
- 첨부 이미지는 `vault/Assets`에 저장하고 문서에서 바로 표시
- 문서를 선택해 전문을 읽고 목록 또는 상세 화면의 수정 버튼으로 편집
- 제목, 카테고리, 태그, 본문, 이미지를 수정하고 저장 실패 시 입력 내용 유지

담당 API: `app/routers/wiki.py`

## 8. 팀 채팅

- `/chat`에서 로그인 이름으로 공용 팀 라운지 자동 참여
- 로그인 계정으로 자동 참여, 별도 이름 입력·변경 경로 제거 및 기존 대화 유지
- 채팅방 상단·메시지·참여자·공유 파일 작성자를 `이름_직함`으로 표시, 새 메시지의 전송 당시 이름·직함 보관
- 본인 메시지를 최초 전송 후 2분 이내 우클릭 또는 Shift+F10으로 수정·삭제, 서버에서 작성자·시간 확인
- 수정 표시와 삭제 표시, 삭제 첨부의 공유·다운로드 차단, 변경 커서를 통한 다른 참여자 화면 동기화
- 여러 참여자 간 메시지 자동 갱신과 현재 참여자 표시
- 줄바꿈, 이전 대화 조회, 실패한 전송 재시도
- 파일 선택과 드래그 첨부, 파일만 전송, 여러 파일 공유 및 다운로드
- 파일당 20MB, 메시지당 5개 첨부, 본문 4,000자 제한
- SQLite 트랜잭션과 요청 ID를 이용한 동시 전송 및 중복 저장 방지
- 공유 전 첨부 파일은 업로더만 메시지에 연결할 수 있으며, 공유된 파일은 모든 참여자가 다운로드

담당 API: `app/routers/team_chat.py`, 저장소: `app/team_chat.py`

## 9. 영수증

- ERP `/receipts`에서 사진 미리보기, 등록자, 자동 등록일, 내용 요약을 최신순 행 목록으로 조회
- 행 또는 보기 버튼을 누르면 사진·등록자·등록 일시·전체 내용·파일명을 상세 팝업으로 표시
- 상세 팝업에서 내용 수정·사진 교체·저장·취소 및 확인 후 영수증과 사진 삭제, 저장 실패 시 입력 유지
- 닫기 버튼·Esc·바깥 영역 클릭으로 팝업 닫기, 원본 사진 새 창 열기
- 24건 단위 페이지 이동, 첫 페이지 10초 자동 갱신 및 팝업 열람 중 갱신 일시 중단
- ERP와 같은 포트의 `/receipt-upload`에서 간단한 등록 전용 화면 제공, `python run.py`로 함께 실행
- 사진 최대 20장(사진당 10MB 이하 JPG/PNG/WEBP/GIF), 추가 선택·개별 미리보기·제외
- 선택한 사진 전체를 영수증 1건에 함께 저장하고 등록 상태 표시, 목록에 첨부 사진 장수 표시
- 한국 시간 기준 자동 날짜 기록, 실패 시 입력 유지, 같은 사진·내용·요청 ID로 전체 재시도하여 중복 방지
- 상세 팝업에서 사진을 선택해 개별 원본 보기·다운로드, 수정 시 여러 사진으로 전체 교체
- 기존 단일 사진 영수증은 별도 변환 없이 조회·수정·다운로드 지원
- 공용 `vault/Receipts`에 원본 사진과 JSON 내용을 함께 저장한 후 목록에 공개

담당 API: `app/routers/receipts.py`, 저장소: `app/receipts.py`, 등록 화면: `app/receipt_static/index.html`

## 10. Info

- ERP 로그인 후 별도 접근 비밀번호 입력. 관리자도 동일하게 확인하며, 탭 이동·새로고침·로그아웃·30분 만료 시 다시 잠금
- 목록·등록·수정·삭제·PWD 조회 API를 로그인 세션에 연결된 임시 접근 토큰으로 보호, 비밀번호 10회 오입력 시 15분간 제한
- `/id-info`에서 회사 공유 계정의 구분, ID, PWD, 기타 정보를 표로 조회
- 등록 일시·최종 변경 일시 자동 기록, 한국 시간(KST) 기준 초 단위 표시 및 수정 저장 후 즉시 갱신
- 구분만 필수인 추가·수정 폼과 확인 후 삭제 지원
- PWD는 기본 가림, 필요할 때 보기·숨기기 전환
- 저장 실패 시 입력 유지, 목록 응답에서는 PWD 제외, API 응답 캐시 방지
- `vault/IdInfo/id-info.sqlite3` 로컬 저장, Git 및 Markdown 노트 검색에서 제외

담당 API: `app/routers/id_info.py`, 저장소: `app/id_info.py`

- 시계 중앙의 시작·일시정지·재개 버튼, 입력란 옆 초기화 버튼
- 부채꼴 영역·바늘과 중앙 디지털 분·초로 남은 시간 표시
- 마우스·터치·키보드 조절, 실행 중 편집 잠금 및 일시정지 후 재설정
- 60분 초과 입력 시 눈금 확장, 드래그 중 눈금 유지 및 12시 경계에서 최소·최대 시간 제한
- 브라우저 로컬 저장, 메뉴 이동·새로고침 후 복원, 같은 브라우저 창 간 동기화
- 종료 시각 기준 계산으로 백그라운드 실행 및 절전 이후 시간 오차 방지
- 실행 중 다른 ERP 탭에서는 오른쪽 아래에 남은 시간과 빨간 막대 표시, 클릭 시 뽀모도로로 이동
- 전체 설정 시간 대비 남은 비율로 막대 갱신, 일시정지·초기화·완료 또는 뽀모도로 탭에서는 숨김
- 로그인 이름으로 시작한 실행을 오른쪽 기록 패널에 표시, 패널 열기·닫기 상태 기억, 타이머·미전송 기록 계정별 저장
- 이름·실제 집중 시간·목표 시간·시작 시각·상태 표시, 일시정지 시간 제외 및 재개 시 동일 기록 유지
- 초기화·시간 재설정 시 기존 실행을 종료하고 실제 집중 시간 보존
- 25건 단위 기록 조회, 패널이 열려 있는 동안 최신 목록 자동 갱신
- `vault/Pomodoro/pomodoro.sqlite3`에 공유 실행 기록 저장, 저장 실패 시 브라우저 보관 후 중복 없이 재전송

화면: `app/static/pomodoro.js`, 타이머 로직: `app/static/pomodoro-timer.js`, 기록 화면·저장 동기화: `app/static/pomodoro-history.js`, API: `app/routers/pomodoro.py`

- 등록·수정 시각 자동 기록, 로컬 `vault/RemoteWork/remote-work.sqlite3` 및 `Uploads/`에 영구 저장 및 Git 제외

담당 API: `app/routers/remote_work.py`, 저장소: `app/remote_work.py`, 화면: `app/static/remote-work.js`

## 13. 연차·반차·재택

- `/attendance`에서 등록 팝업을 열어 구분·날짜·선택 메모 입력, 이름은 로그인 계정에서 자동 적용
- 연차·재택은 기간 지정, 반차는 하루의 오전·오후 선택
- 등록 즉시 캘린더에 표시, 캘린더 보기로 해당 일정 상세를 열어 수정·삭제
- 캘린더와 같은 Markdown 노트를 사용하며 수정·삭제와 서버 재시작 후에도 일치
- 월·구분별 조회, 전체 기간 조회, 25건 단위 페이지 이동, 기존 캘린더의 관련 일정 포함

API: `app/routers/attendance.py`, 화면: `app/static/attendance.js`, 저장 위치: `vault/Calendar`
