# QA 체크리스트

- 대시보드가 오늘 날짜 기준으로 TODO, 일정, 작업, 프로젝트 수를 표시하는가
- 과거 미완료 TODO가 오늘 페이지 진입 시 자동 이월되는가
- 달력 날짜 클릭 후 일정 등록 시 해당 날짜에 일정이 표시되는가
- 작업 등록 시 start date와 end date가 작업바 길이에 반영되는가
- end date가 start date보다 빠른 작업 등록은 차단되는가
- 프로젝트 등록 후 작업/TODO에서 프로젝트 선택지로 나타나는가
- 주간 보고서 생성 시 `vault/Reports`에 Markdown 파일이 생성되는가
- 새로고침 후에도 Vault에 저장된 데이터가 유지되는가
- 회의록과 위키 목록에서 기존 문서를 수정하고 취소하거나 저장할 수 있는가
- 수정 후에도 문서 ID, 프로젝트 연결, 본문 속 제목·목록, 첨부 이미지, 변경 이력이 유지되는가
- 회의록 수정에서 안건이 지워지지 않고 시작 시간을 비울 수 있는가
- 저장 실패 시 편집 내용이 유지되고, 새 문서 작성이 기존 문서를 덮어쓰지 않는가
- 서로 다른 브라우저에서 이름으로 팀 채팅에 참여하고 메시지를 주고받을 수 있는가
- 이름을 변경하고 새로고침해도 참여 정보와 대화 기록이 유지되는가
- 파일만 전송하거나 여러 파일을 첨부하고 다른 참여자가 원본 파일을 다운로드할 수 있는가
- 업로드 크기 초과와 잘못된 첨부가 차단되고, 전송 실패 시 작성 내용이 유지되는가
- 동시 메시지 전송 및 재시도 시 메시지가 누락되거나 중복 저장되지 않는가
- 이전 대화 조회와 모바일 채팅 입력창이 정상적으로 동작하는가
- 재택근무 기록 등록·수정이 팝업에서 열리고 취소·닫기·Esc로 기존 기록 변경 없이 닫히는가
- 재택근무 내용 입력창의 Ctrl+V/⌘V와 이미지 붙여넣기 버튼으로 클립보드 이미지를 추가하며 일반 텍스트 붙여넣기도 유지되는가
- 재택근무 팝업에서 파일 버튼 선택·드래그 앤 드롭·이미지 미리보기·첨부 취소가 가능하고 저장 후 원본 보기·다운로드가 가능한가
- 재택근무 저장 실패 시 내용·선택 파일이 유지되고, 수정 저장 시에만 첨부 삭제가 반영되는가
- 기존 재택근무 기록이 유지되며, 잘못된 이미지·20MB 초과·10개 초과 첨부가 차단되는가
- 영수증 등록에서 여러 사진을 선택·추가·제외하고 사진마다 개별 영수증으로 저장할 수 있는가
- 영수증 일부 등록 실패 및 응답 지연 후 재시도 시 완료된 건을 중복 저장하지 않는가
